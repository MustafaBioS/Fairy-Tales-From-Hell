**<h1>Fairy Tales From Hell</h1>**
**Fairy Tales From Hell is a roblox Evade style game where you have a magic wand and you try to run from shrek or harry potter (ts was julia's idea 😭)**
--- 
**<h1>Keybinds</h1>**
> **W -> Move Forward<br>
> S -> Move Backwards<br>
> D -> Move Right<br>
> A -> Move Left<br>
> CTRL -> Slide<br>
> C -> Crouch<br>
> Shift -> Sprint<br>
> Space -> Jump<br>
> Left Click -> Attack<br>**
